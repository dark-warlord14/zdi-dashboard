## Vulnerability Details

This vulnerability allows remote attackers to execute arbitrary code on affected installations of Microsoft Skype. User interaction is required to exploit this vulnerability in that the target must visit a malicious page or open a malicious file. The issue results from the use of a vulnerable version of Google Chromium. An attacker can leverage this vulnerability to execute code in the context of the current process.
